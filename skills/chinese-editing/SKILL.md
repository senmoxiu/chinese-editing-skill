# 中文编辑

帮助读者准确理解中文内容。先按用户要求确定编辑范围，再读取相应参考；不要把所有文体统一成正式报告。

## 选择任务

| 用户意图 | 处理方式 | 按需参考 |
| --- | --- | --- |
| 只改空格、标点、错字、大小写；排版校对 | 局部修改，不重写结构和语气 | [排版](references/typography.md) |
| 审稿、整理笔记、润色文章、检查技术报告 | 结合受众检查组织、术语和论证；保留作者声音 | [文档](references/documents.md) |
| 编写或改善按钮、状态、错误提示、API 说明、操作步骤 | 先理解真实行为，再组织可执行的说明 | [技术与界面文案](references/technical-copy.md) |

“检查、评审、指出问题”默认只报告；“修改、校对、润色”才交付修订稿或按授权编辑指定文件。新写内容按交付物选择模式。“整理”若无法确定是否包含重写，先做最小的结构和一致性调整；只有会实质改变观点或范围时才提问。复合任务读取确有需要的参考，不默认加载全部。

## 编辑边界

- 先看用户要求和目标项目已有的文风、术语、地区与交付规范。用户或项目明确要求优先于本 skill 默认值；若与已确认的交付要求冲突，说明冲突，不冒称合规。
- 修改前标记事实、数值、来源、前提、否定、例外和确定程度。不能把“可能、建议、计划、最多”改成确定结论，也不能补造时限、原因、功能和引用。
- 对原文中可能错误或矛盾的事实，指出疑点并核实；不为保真掩盖问题，也不凭猜测改正。
- 保护命令、代码、URL、路径、公式、正则、键名、枚举、占位符和固定引文。技术字面量的内部字符不能按中文排版规则全局替换。
- 在代码或本地化资源中修改已明确指定的可见文案时，保持键、变量、转义、插值与语法不变。先识别格式，不对整个文件做文本替换。
- 直接引语、日志、错误原文和案例中的故意反例原样保留。需要修订引用时，把建议与引文分开；用户明确要求编辑引用本身时再处理。
- 本 skill 提供编辑指导，不授权安装工具、全库批改、提交或发布。只操作当前任务指定的文本与文件。

## 默认选择

适用于没有既定格式的简体中文横排正文：使用“弯引号”和内层‘单引号’，中西文按语义留白，专有名称遵循官方拼写。这些是编辑默认值，不把其他地区或项目采用的直角引号判成普遍错误。

语气随文章用途和作者调整。学习笔记可以保留第一人称与疑问，品牌文案可以有情绪；事实和功能声明仍须有依据。仅排版时，不附带去除“AI 味”或改成学术语气。

## 工作与交付

1. 读取待编辑片段及足够的邻接上下文，确认任务、受众、载体和已有规范。短句任务不要求扫描全仓库。
2. 选参考，辨认受保护内容，在授权范围内修改。已清楚且一致的句子可以原样保留。
3. 对照原文复查数字、条件、否定范围、实体、引用及机器语法；文件编辑查看实际差异。只有涉及相应格式时，运行项目已有的适当检查。
4. 交付修订稿或文件，并简述必要的修改与未决问题。检查模式给出原文位置、问题、依据和建议，区分事实／语义问题、规范不一致与可选风格。

短文本直接给结果，不固定附长报告。不要把结构检查通过说成语义无误，也不要把未运行的渲染、链接或应用测试说成成功。处理 Word、PDF 等载体时使用宿主已有的编辑工具；没有时交付文本建议并说明未修改原文件。

需要追溯规则、比较上游或更新 skill 时，读取[来源与取舍](references/sources.md)；普通编辑无需读取。
